# shapeic
SHAPEIC: Systematic and Hierarchical Analog Platform for Exploration of Integrated Circuits


## Publications

ShapeIC builds upon the methodology developed in the following works:

* D. Arévalos, J. Marin, K. Herman, J. Gomez, S. Wallentowitz, and C. A. Rojas,
  **“A Topology-Independent and Scalable Methodology for Automated LDO Design Using Open PDKs,”**
  *Electronics*, vol. 14, no. 17, 3448, 2025.
  [Paper](https://www.mdpi.com/2079-9292/14/17/3448) · [DOI](https://doi.org/10.3390/electronics14173448)

* D. Arévalos, J. Marin, K. Herman, and C. A. Rojas,
  **“Leveraging Lookup Tables for Efficient LDO Design Exploration using Open-Source CAD Tools and IHP-Open130-G2 PDK,”**
  *2024 31st International Conference on Mixed Design of Integrated Circuits and System (MIXDES)*, pp. 124–129, 2024.
  [IEEE Xplore](https://ieeexplore.ieee.org/document/10614033) · [DOI](https://doi.org/10.23919/MIXDES62605.2024.10614033)
